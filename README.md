# Hell's Deck — Helluva Boss Fan Card Game

Hell's Deck เป็นเกมการ์ด Roguelike Deckbuilder แบบเล่นคนเดียว สไตล์ Hearthstone เปิดเล่นในเบราว์เซอร์บนเครื่องตัวเองได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม

## วิธีเปิดเกม
ดับเบิลคลิกไฟล์ `index.html` เกมจะเปิดใน Chrome หรือ Edge
ระบบจะบันทึกความคืบหน้าของรันไว้ในเบราว์เซอร์ให้อัตโนมัติ

## ใส่รูปภาพเอง
วางไฟล์รูปตามชื่อ id ตัวพิมพ์เล็ก (รองรับ `.webp` `.png` `.jpg` `.jpeg` — เกมลอง `.webp` ก่อน แนะนำให้ใช้เพราะไฟล์เล็ก)

| ประเภท | โฟลเดอร์ | ตัวอย่าง |
|---|---|---|
| การ์ด | `assets/cards/` | `assets/cards/moxxie.png` |
| ฮีโร่ | `assets/heroes/` | `assets/heroes/blitzo.png` |
| บอส | `assets/bosses/` | `assets/bosses/striker.png` |
| สมบัติ | `assets/relics/` | `assets/relics/r_echo.png` |

ดู id ของการ์ดแต่ละใบได้ที่เมนู **📚 คลังการ์ด** ในเกม ถ้ายังไม่มีไฟล์รูป เกมจะแสดง emoji แทน
ถ้าหน้าตัวละครหลุดกรอบตอนแสดงบนการ์ด ปรับจุดโฟกัสได้ที่ `ART_FOCUS` ใน `js/data.js`
รูปการ์ดควรเป็นแนวนอนหรือจัตุรัส ส่วนรูปฮีโร่และบอสควรเป็นจัตุรัส เพราะจะถูกครอปเป็นวงกลม

## โครงสร้างไฟล์
- `js/data.js` เก็บการ์ด ฮีโร่ บอส สมบัติ และร้านค้า **แก้หรือเพิ่มการ์ดได้ที่ไฟล์นี้**
- `js/engine.js` เก็บกฎการต่อสู้ทั้งหมด
- `js/ai.js` เก็บ AI ของบอส
- `js/ui.js` เก็บหน้าจอการต่อสู้
- `js/main.js` เก็บโฟลว์ของรัน ได้แก่ เลือกฮีโร่ เลือกการ์ด แผนที่ รางวัล สมบัติ และร้านค้า
- `css/style.css` เก็บหน้าตาของเกม

## ลำดับรัน
1. เลือกฮีโร่ (เด็คพื้นฐาน 10 ใบ) แล้วเลือกการ์ดเพิ่ม 5 ใบ จาก 10 ใบ
2. สู้บอสทั้ง 8 ตัวตามลำดับ HP 10 / 20 / 30 / 50 / 70 / 90 / 120 / 150
3. ชนะบอสแต่ละตัว ได้เลือกการ์ดสูงสุด 3 ใบ จาก 10 ใบ
4. หลังบอสตัวที่ 2, 4, 6 จะสุ่มสมบัติมา 3 ชิ้น หยิบได้ 1 ชิ้น
5. หลังบอสตัวที่ 3 และ 6 ได้เข้าร้านค้า
   - ได้เหรียญ 3 เหรียญ และเหรียญรีเซ็ตทุกครั้งที่เข้าร้าน
   - สุ่มสินค้ามา 5 อย่างจากทั้งหมด 12 อย่าง
   - ราคา 1 ถึง 3 เหรียญ ตามความแรงของสินค้า

## การ์ด
- **การ์ดผู้เล่น 93 ใบ** ในจำนวนนี้มีตัวละครหลักระดับตำนาน (กรอบทอง) 20 ตัว
- **ตัวละครจะเก่งขึ้นเมื่อมีคู่หูตามความสัมพันธ์ในซีรีส์** อยู่บนบอร์ด เช่น
  - Blitzø + Stolas
  - Moxxie + Millie
  - Blitzø + Loona
  - Vortex + Loona
  - Stella + Andrealphus
  - Asmodeus + Fizzarolli
  - Crimson + Moxxie
  - Barbie Wire + Blitzø
  - Glitz + Glam
  - Collin + Keenie + Cletus
- **ตัวละครของบอสและฮีโร่ทุกตัวมีการ์ดมินเนี่ยนให้ผู้เล่นใช้ได้ด้วย**
- **มีการ์ดที่ใช้เคลียร์บอร์ด** เช่น Hellfire Rain, Hell's Purge และ Frozen Wastes รวมถึงการ์ดที่เคลียร์บอร์ดได้เมื่อทำเงื่อนไขครบ เช่น Paimon และ Satan
- **มีการ์ดที่ยิงบอสโดยตรง** เช่น Pentagram Strike, Infernal Lance, Contract Payout และ Mammon
- **การ์ดจัดการเด็ค** เรียกมินเนี่ยนออกจากเด็ค (📤) สับการ์ดเข้าเด็ค (🔀) และส่งมินเนี่ยนบนบอร์ดกลับเข้าเด็ค บอสทุกตัวมีการ์ดแบบนี้ เด็คบอสจึงมี 21–26 ใบและไม่หมดเร็ว
- **สายวนเด็คของผู้เล่น** เช่น Reborn Imp (ตายแล้วกลับเข้าเด็คพร้อม +1/+1 สะสม), Lost Sinner (สับ Lost Soul ที่ทำงานทันทีตอนจั่ว), Cursed Paperwork (สับระเบิดใส่เด็คบอส), Time Loop, Mimzy และตัวรับผลอย่าง Soul Archivist กับ Stolas's Prophecy
- **การ์ดปรับค่าร่าย** ลดค่าร่ายของเรา (Hellmart Sale, Overtime, Hellmart Cashier, Grimoire Keeper) หรือเพิ่มค่าร่ายของศัตรู (Red Tape, Hell Bureaucrat, Price Gouge)
- **สุ่มคนเริ่มก่อน** ฝ่ายที่เริ่มทีหลังได้ 🪙 Hell Coin
- **บอสแต่ละตัวมีคอมโบของตัวเอง** เช่น Striker + Striker's Steed, Goetia Knight + Paimon
- **ชี้การ์ดค้างไว้** จะเห็นคำอธิบายความสามารถทั้งหมดของการ์ด และการ์ดคู่หูที่คอมโบด้วย ส่วนการ์ดในมือที่ลงแล้วจะเกิดคอมโบจะมีป้าย 💞
- **ประวัติการเล่น** ชี้แต่ละรายการเพื่อดูภาพการ์ดที่ถูกใช้
- **ความเร็วแอนิเมชัน** ปรับ ช้า / ปกติ / เร็ว ได้ที่แถบซ้ายในหน้าต่อสู้ การ์ดที่บอสเล่นจะแสดงให้เห็นก่อนเอฟเฟคทำงาน
- **ปรับค่าตัวเลขได้ที่ `js/data.js`** ทั้งเวลาเปิดร้าน จำนวนเหรียญ จำนวนสินค้า และความถี่ของสมบัติ (ดูค่า `SHOP_AFTER_BOSS`, `GOLD_PER_SHOP`, `SHOP_SLOTS`, `RELIC_EVERY`)

> เป็นแฟนเกมสำหรับเล่นส่วนตัว ตัวละครและชื่อต่างๆ เป็นลิขสิทธิ์ของเจ้าของผลงาน
